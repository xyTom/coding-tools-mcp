代理模式与直连模式

暴露方式影响客户端看到的工具目录，不改变上游能力本身。

代理模式（推荐）

只直接暴露固定工具和置顶工具，其余工具保留在可搜索目录中。

直连模式

直接暴露过滤后的完整工具集合，适合工具规模较小或客户端明确需要完整列表时。

凭据策略

管理台读取时遮蔽敏感值，表单编辑会保留隐藏字段。

支持直接值、secret:保险箱名称 和 env:变量名；展示页不会回显凭据值。

工作区

每个 HTTP 会话在初始化时绑定一个已校验工作区，生命周期内不可切换。

工作区是文件与进程隔离边界

当前目录、保留输出、进程表、项目指令和上游工具快照都按会话独立。
