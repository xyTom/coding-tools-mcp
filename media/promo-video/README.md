# Promo video (Remotion)

45-second promotional video for Coding Tools MCP, defined entirely in code —
edit the copy in `src/Promo.tsx`, then re-render.

```bash
npm install
npm run studio   # live preview + timeline editor
npm run render   # writes out/coding-tools-mcp-promo.mp4 (1920x1080, 30 fps)
```

Scene map (frames @ 30 fps): title 0–120 · clients 120–360 · terminal demo
360–600 · safety modes 600–870 · unique tricks 870–1140 · CTA 1140–1350.

The rendered file is not committed; published copies are attached to GitHub
Release assets.
