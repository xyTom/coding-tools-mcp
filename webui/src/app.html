可选功能

Coding Tools MCP Codex Agent 工作台

这是可选的浏览器版 Codex Agent 工作台，不是 GPT/ChatGPT 网页，也不是 Admin 页面。它在执行主机上调用已经登录的 Codex CLI；如果只通过 Claude、Cursor、Codex 等外部客户端使用 MCP，可以忽略 /app。

/mcp

外部 AI 客户端通过这里使用 Coding Tools MCP 工具。

/admin

管理员通过这里管理服务器，使用独立的 CODING_TOOLS_MCP_ADMIN_TOKEN。

/app

人类通过浏览器操作持久化 Codex Agent Session，使用普通 bearer 或 OAuth access token。

运行前提

执行主机必须安装 Codex CLI，并已完成 Codex 登录（例如先运行 codex login）。本地 Workspace 使用本机；Runner Workspace 使用对应 Runner 主机。

三套凭据互不相同

/app 使用 CODING_TOOLS_MCP_AUTH_TOKEN 或 OAuth access token；/admin 使用 CODING_TOOLS_MCP_ADMIN_TOKEN；Codex 模型使用执行主机上的 Codex CLI 登录凭据。三者不能互相替代。

持久化由两部分共同完成

持久化由 Coding Tools MCP SQLite 与 Codex thread store 共同完成。前者保存 Agent Session 元数据，后者保存模型 thread 与对话连续性。

准备完成后，选择左侧历史 Session，或在当前 Workspace 创建新的 Codex Session。页面刷新不会自动重复最后一次 Turn。
