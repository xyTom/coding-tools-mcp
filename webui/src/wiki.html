1. 从命令行启动

1. Start from the command line

python -c "import secrets; print(secrets.token_urlsafe(32))"
cd C:\path\to\coding-tools-mcp
python -m pip install -e .
$env:CODING_TOOLS_MCP_AUTH_TOKEN = "<ordinary user token>"
$env:CODING_TOOLS_MCP_ADMIN_TOKEN = "<separate Admin token>"
coding-tools-mcp --workspace "G:\path\to\your\project" --host 127.0.0.1 --port 8765

Admin token 只用于一次性 POST /admin/api/session 交换；之后使用 HttpOnly + SameSite=Strict 的服务器端 Admin Session。原始 Admin token 不写入 Web Storage、URL 或可读 Cookie。

The Admin token is used only for a one-time POST /admin/api/session exchange; afterwards requests use a server-side Admin Session with an HttpOnly, SameSite=Strict cookie. The raw Admin token is never written to Web Storage, URLs, or script-readable cookies.

3. 会话连续性

3. Conversation continuity

Conversation 是统一产品对象。Transcript、上下文证据和 Agent execution 分层存储；MCP transport session 只是短期传输身份。精确匹配 principal、client window 和 workspace/repo scope 才能自动恢复；身份缺失或变化时必须显式 resume。continuation 和 handoff 只读取有界结构化事实，不重建隐藏模型上下文。

Codex CLI 登录凭据由执行主机单独管理；Agent 恢复依赖 Coding Tools MCP SQLite 和 Codex thread store。

A Conversation is the unified product object. Transcript, context evidence, and Agent execution remain separate layers; the MCP transport session is short-lived. Exact principal, client-window, and workspace/repo scope must match for automatic recovery; missing or changed identity requires explicit resume. Continuation and handoff read bounded structured facts and do not recreate hidden model context.

4. 安全清单

4. Security checklist

  • 普通 bearer/OAuth、Admin token、Runner credential 和 Codex CLI 登录彼此分开。
  • 不要把 token 放进 URL、二维码、Git、截图或聊天。
  • 公网部署使用 HTTPS/WSS 和已认证隧道，不要暴露 no-auth 服务。
  • Keep ordinary bearer/OAuth, Admin token, Runner credentials, and Codex CLI sign-in separate.
  • Keep tokens out of URLs, QR codes, Git, screenshots, and chats.
  • Use HTTPS/WSS and an authenticated tunnel for public access; never expose a no-auth service.
